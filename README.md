# Flores Amarillas V2 🌻

- Girasoles que crecen al tocar el botón.
- Tallos y hojas animados.
- Flores que se abren una por una.
- Pétalos en varias capas.
- Fondo con muchas estrellas parpadeantes.
- Partículas de corazones y destellos.
- Botón para repetir la floración.
- Música opcional.

Para la música, coloca tu MP3 en esta carpeta con el nombre exacto:
`flores-amarillas.mp3`

Abre `index.html` con Live Server en VS Code.
